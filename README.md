# Nazar Chepil Coaching

Лендінг для онлайн-коучингу з фітнесу та нутриціології.

## Опис проєкту
Цей вебсайт створений для презентації послуг персонального тренера. Проєкт містить адаптивну верстку та базову структуру для залучення клієнтів.

## Технології
- HTML5
- CSS3
- Деплой: Netlify та GitHub Pages
